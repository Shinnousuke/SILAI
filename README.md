# 🪡 SILAI — AI-Powered Tailoring Marketplace

> **Your clothes. Perfectly fitted.**

SILAI is a digital tailoring marketplace that connects customers with local tailors through a single platform.

Instead of searching for tailors, making multiple calls, checking locations, visiting shops, and repeatedly asking for order updates, SILAI brings the entire tailoring experience into one place.

Customers can discover nearby tailors, find the exact service they need, calculate distance, get directions, contact tailors, book services, track orders, and rate completed orders.

Tailors get their own digital presence and dashboard where they can manage orders, earnings, shop information, availability, and customer ratings.

---

## 🌟 Why SILAI?

The idea for SILAI came from a real-life problem.

One day before Ethnic Day at Christ University, we needed outfits to be altered at short notice. Finding a tailor who was available, offered the required service, and was located nearby turned out to be surprisingly difficult.

The process usually involved:

**Search → Call → Ask → Find Location → Visit → Book → Follow Up**

We wanted to simplify this.

So, we built **SILAI**.

---

## 🎯 Project Objective

SILAI aims to create a convenient digital ecosystem for both sides of the tailoring industry:

### 👗 For Customers

- Find the exact tailoring service required
- Discover nearby tailors
- Calculate distance from the current location
- View tailor details and ratings
- Get directions directly from the platform
- Call tailors directly
- Book tailoring services
- Track order status
- Cancel eligible orders
- Rate completed orders

### 🧵 For Tailors

- Create a digital shop profile
- Get discovered by nearby customers
- Manage incoming orders
- Accept or reject orders
- Update order status
- Track sales and earnings
- View financial analytics
- Monitor customer ratings
- Manage shop timings
- Set working days
- Add vacations and holidays
- Update shop location and information

# ✨ Key Features

## 🔍 1. Tailor Discovery

Customers can browse registered tailors and discover services based on their requirements.

Each tailor profile can display:

- Shop name
- Specialty
- Location
- Rating
- Starting price
- Opening and closing hours
- Distance from the customer
- Contact information

---

## 📍 2. Location & Distance Calculation

SILAI uses the user's browser location to calculate the approximate distance between the customer and registered tailors.

The platform uses:

- Browser Geolocation API
- Latitude & Longitude
- Haversine distance calculation
- Reverse geocoding

This allows customers to identify tailors located closer to them.

---

## 🗺️ 3. Direct Directions

Customers don't need to manually search for a tailor's address.

SILAI can generate directions to the tailor's location through Google Maps.

---

## 📞 4. Direct Calling

Customers can directly call the tailor from the website using the registered shop contact number.

This reduces the number of steps required to communicate with a tailor.

---

## 📅 5. Service Booking

Customers can book tailoring services through the platform.

Services include:

- New Stitching
- Alterations
- Blouse Stitching
- Repairs
- Custom Tailoring
- Other tailoring requirements
